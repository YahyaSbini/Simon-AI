# Simon-AI

## Tech stack

- Frontend: Next.js + React + TypeScript
- UI: Tailwind CSS + shadcn/ui
- Backend: Next.js API routes or NestJS
- Database: PostgreSQL
- ORM: Drizzle
- Cache: Redis
- Auth: Better Auth / Auth.js

## Skills

Repository skills live in `.agents/skills/`:

- `brand-identity` — Stick & Twig Rabbit colors, fonts, logo usage.
- `ui-standards` — consistency, minimalism, responsiveness, Tailwind, transitions.
- `anti-ai-ui` — rules for UI that does not look AI-generated.

Brand assets and the full guideline PDF live in `brand/`.
